# 1.0.5 — unsigned prerelease

Apple Silicon macOS, 2026-11-17. Ad-hoc signed for integrity only: **no Developer
ID signature or notarization**. Gatekeeper rejects the app in local assessment.
This is a test prerelease, not a claim of complete production acceptance.

## Fixed and improved

- Built-in NVIDIA connection: choose NVIDIA, add keys and a chat model, then
  **Save & Apply**. The helper translates Messages/Chat Completions and puts all
  enabled NVIDIA keys before retained fallback providers. No third-party bridge.
- Provider-first switching: try A1 → A2 → B1; models belong to providers; existing
  explicit-key policies retain their order. Paused keys are skipped, caller errors
  stop switching, and a started response stream is never replayed.
- Settings recovery: choose a validated backup, inspect timestamp/model/destination
  and helper availability, then confirm. Invalid originals are preserved privately.
- Failed/interrupted saves: shared locking, private before-image journal, explicit
  restore/keep recovery, rollback-error reporting and preservation of external edits.
  Failed activation restores prior policy/key/helper state; repeated identical keys
  are reused. Managed operations are recoverable, not multi-file crash-atomic.
- Valid provider drafts survive switching/relaunch; completed custom endpoint/model
  drafts can be reopened. Key input is excluded from draft storage. Review shows
  saved and pending values. Old direct NVIDIA setup gets an activation warning.
- Bounded saved switching history, HTTP-date/seconds Retry-After, clearer outcomes,
  private concurrent secret writes, bounded backup reads and stronger path checks.
- Four-screen workflow, information buttons, accessible recovery confirmations,
  clearer field/control contrast and native-command dispatch off the main thread.
- DMG packaging works without Finder automation; the mounted/copied artifact and
  signature are checked. Earlier installed app/login agent/caches were removed
  as requested; keys/settings/backups were preserved. No replacement was installed.

## Setup and migration

For multiple platforms: **Providers & keys** → choose provider → add its keys →
choose model → **Add provider to switching order**. Repeat, then review the cards
under **Switching** and **Save & enable automatic switching**. Keys in one account
may share limits. A key check is separate from successful model inference.

After upgrading an old direct NVIDIA setup, select NVIDIA and a chat model, then
Save & Apply to install the local translation endpoint. Keep the helper running.
Closing the GUI does not intentionally stop it. Login start is opt-in.

If an interrupted-save banner appears, review its restore/keep choice before
writing again. Restore can replace later edits and preserves current files first.
Private journal/recovery snapshots contain key copies; never upload them. Resolve
an outstanding journal before downgrading. Keep ordinary settings backups and
private credential data when uninstalling the GUI.

## Verification

- **215 frontend tests**, lint, format, TypeScript and production build pass.
- **401 Rust tests**, fmt and clippy with warnings denied pass; six environment/
  live checks are ignored by default.
- Real installed Claude Code explicitly tested against the final packaged helper:
  Save → generated helper → A1 returns 401 → A2 streams a Read tool call → actual
  CLI reads a disposable file → A2 streams the final answer. Fixture home contains
  spaces and quotes; no real keys or paid endpoints are used in this test.
- Signature integrity, DMG checksum, read-only mount, copy verification and binary
  equality pass. Apple trust assessment rejects the ad-hoc signature as expected.
- Root npm/macOS OSV dependency checks find no affected shipped packages. The
  unavailable external bridge has three moderate advisory records in its separate
  lock; install/start/apply stay disabled. Source/history secret scans pass, with
  one exact historical synthetic loopback-token fingerprint ignored.
- OpenRouter authenticated current-key check returned 200 using system TLS. The
  prior NVIDIA key was rejected; updated-key inference awaits user readiness.

## Known limits and unfinished acceptance

NVIDIA supports text, model-specific images and function tools, including streamed
arguments. Document/server/computer tools and structured output are rejected.
Output is capped at 32,768 tokens; Nemotron 3 thinking is disabled. Other OpenAI-only
providers remain unavailable. Native/compatible attempts are bounded to 30 seconds; NVIDIA
streams can run 30 minutes with 120-second idle reads. The 60-second retry budget is checked between
attempts, not a strict whole-request deadline. Timeouts can still incur upstream
processing or charges.

Small-window/200% zoom/VoiceOver, actual reboot/login, clean-Mac installation and
successful hosted NVIDIA inference remain unverified. Native window/provider
screen was readable, but control/capture failures blocked full native acceptance.
Blank model keeps the saved override; removing it currently requires manual edit.
Full manual per-line review is not complete; inventory, targeted invariant review,
automated checks and remaining tasks are recorded in the audit. Do not call all
acceptance tasks finished from automated test counts alone.
