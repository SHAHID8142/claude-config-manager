# 1.0.7 — NVIDIA conversation-role fix (unsigned prerelease)

Apple Silicon macOS, 2026-11-18. Fixes the local adapter rejecting text system
messages inside a Claude conversation with **400 unsupported message role**.
A minimal one-turn key check did not cover this conversation format in1.0.6.

- Accept text system messages, collecting active instructions into NVIDIA's one
  initial system message in original order. Top-level instructions come first.
- Respect `clear_at: never` and `next_user_message`; a later user turn, including
  tool-result delivery, expires the latter. Do not silently keep stale reminders.
- Keep function-call/result IDs and ordering intact. Dynamic tool-state changes,
  per-message effort and unsupported roles receive explicit errors. Claude-native
  prompt-cache placement/thinking signatures are not portable to NVIDIA.
- Prevent a second helper for the same user from opening another port and replacing
  active state. An OS file lease survives normal runtime and releases on exit/crash.
- Include helper version in health metadata to verify a running process upgraded.
- CLI fixtures now use the actual saved NVIDIA model with normal tool declarations,
  in bare and default startup modes. An idle probe no longer crashes the fake server.

Current official references checked before the fix:
[Claude mid-conversation system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages)
and [NVIDIA hosted Chat Completions](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-ultra-550b-a55b-infer).
The process lease follows [Rust File locking](https://doc.rust-lang.org/std/fs/struct.File.html#method.try_lock).
This is explicit instruction-format translation, not identical Claude-native
cache/runtime semantics or support for every feature of every CLI extension.

409 Rust tests and219 frontend tests pass; fmt, clippy, lint, formatting and
TypeScript pass. Packaged CLI, live compatibility and final artifact checks are
recorded in the release evidence. Existing keys and unrelated settings are retained.

If a previous helper is still running, use **Switching → Restart & clear pauses**
after upgrading. The helper must remain running for NVIDIA. This release is ad-hoc
signed only: no Developer ID/notarization, and Gatekeeper rejects local assessment.
Native accessibility/minimum-window/reboot/clean-Mac and exhaustive manual review
remain unverified. See the [guide](../USER_GUIDE.md) and [audit](../audits/2026-11-18-project-review.md).
