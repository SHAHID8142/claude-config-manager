# 1.0.3 — explain unavailable provider activation

Local candidate, 2026-11-17. No GitHub release or installed-app replacement.

The current native window had NVIDIA NIM selected, a stored key, model, context
and role entries. Save & Apply was disabled because the app's NVIDIA hosted API
integration is unimplemented. The footer incorrectly told the user to fix a
highlighted field, and the badge incorrectly directed them to bridge setup.

Changes:

- Persistent explanation beside the provider: it cannot be applied in this version.
- Specific Save-disabled reason connected with aria-describedby.
- Unavailable badge replaces the false bridge-setup direction. The unavailable
  provider no longer gets the green capability badge.
- Unsupported key test disabled; catalog browsing and key storage remain available.
- Catalog labels do not imply successful integration; context hint qualified by CLI/model.
- The backend protocol guard remains intact. This is a clarity fix, **not NVIDIA
  hosted inference/bridge implementation**. No key or settings changed.

Verification: frontend lint/format/typecheck and all 205 tests passed. New
regression proves a stored key/model cannot bypass the NVIDIA restriction and
that a supported provider invokes Apply and shows success using fixture IPC.
No real inference was requested. Rust implementation is unchanged from 1.0.2;
its previous 345 passing tests are baseline evidence, not a fresh 1.0.3 suite run.

The current user window was left open to preserve pending entries. It continues
running its loaded older interface until restarted. New artifacts are under
`src-tauri/target/release/bundle/`; artifact verification is in `1.0.3-evidence.json`.
Previous 1.0.2 DMG retained. macOS Developer ID/notarization remains unavailable.

Research: NVIDIA's [hosted model API](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-ultra-550b-a55b-infer)
documents OpenAI chat completions. NVIDIA separately documents Anthropic-compatible
[NIM deployments](https://docs.nvidia.com/nim/large-language-models/2.1.6/ai-assistant-integrations/claude-code.html);
this does not establish the hosted endpoint accepts the same protocol. Checked
before changes. Modern Web Guidance `forms` informs persistent, specific feedback.
