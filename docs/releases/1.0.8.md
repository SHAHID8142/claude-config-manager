# 1.0.8 — ordered model fallback (unsigned macOS release)

Apple Silicon macOS,2026-11-18. Each provider now supports a primary model and up
to4 ordered fallback models. Open **Switching → provider → Model order**, load
catalog suggestions or enter model IDs, add choices, reorder them and **Save order**
(or **Save & enable automatic switching** to activate routed mode).

The order is provider → model → enabled keys. Unavailable model errors pause that
model across keys; authentication/credit errors pause the affected key across its
models. Transient failures try the next combination. Generic invalid requests stop;
responses already streaming are never replayed. Network attempts remain bounded
at200 per request, with the existing60-second retry-decision budget. Skipped
combinations do not consume the attempt allowance. Cooldowns survive model reorder
within a multi-model policy. Shared-account quota cannot be inferred reliably.

The model editor has explicit Add/Remove/Move controls, manual entry alongside
catalog suggestions, sequence preview and information buttons. Choosing another
model in provider setup appends it to that provider instead of replacing its first
choice. NVIDIA Save & Apply retains its other models. Activity shows last selected
model. A newer app upgrades its verified older helper before using the new policy.

Existing single-model settings remain valid. Older apps reject `fallbackModels`:
remove alternatives and save with1.0.8 before downgrading, or restore a compatible
policy backup. No user key is changed or fabricated. Real saved policy is not
silently populated with demonstration models.

Current official references checked before implementation:
[NVIDIA single-model requests](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-ultra-550b-a55b-infer),
[Claude API errors](https://platform.claude.com/docs/en/api/errors),
and [OpenRouter ordered model fallbacks](https://openrouter.ai/docs/guides/routing/model-fallbacks).
The app orchestrates its own provider-independent chain rather than sending
OpenRouter-only request fields to NVIDIA.
