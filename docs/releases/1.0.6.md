# 1.0.6 — unsigned prerelease

Apple Silicon macOS, 2026-11-17. Follow-up to the [1.0.5 repair release](1.0.5.md).
No Developer ID signature/notarization; ad-hoc integrity signing only. Gatekeeper
rejects this distribution. Native and hosted-provider acceptance remains limited.

This patch fixes two edge cases found in the final review:

- Draft collections now stay within both 32 entries and 64 KiB of text before they
  are written. Older drafts are evicted first, retaining the most recently edited
  provider. Previously a valid large collection could exceed its own read cap,
  making the next launch ignore all drafts.
- An out-of-range saved history timestamp displays **Unknown timestamp** instead
  of throwing during rendering. Valid events retain machine-readable timestamps.

The built-in NVIDIA adapter, provider-first/key-order switching, selected backups,
interrupted-save recovery, information buttons, draft review, private storage and
redacted history from 1.0.5 remain included. See the [guide](../USER_GUIDE.md).
Neither patch reads, changes or transmits real API keys.

Verification: 219 frontend tests plus lint/format/TypeScript/build pass. The Rust
backend has 401 passing tests with six ignored by default; its production source
is unchanged from 1.0.5. Final packaged CLI, DMG/signature/mount/copy and source
fingerprint checks are recorded in the [artifact evidence](1.0.6-evidence.json).
Source/history secret scans and npm/macOS dependency checks are recorded too.
The release 1.0.5 source passed all three remote CI jobs; 1.0.6 CI is tracked separately.

OpenRouter's current-key check passed 200. Updated-key NVIDIA inference awaits
user readiness; no successful hosted NVIDIA inference is claimed. Native minimum
window/200% zoom/VoiceOver, actual reboot/login/clean Mac and exhaustive manual
per-line/frame review remain unverified. Removing a saved model override still
requires manual edit. The app is a prerelease, not complete production acceptance.

Download the DMG with SHA256SUMS and evidence from this release. Installation does
not migrate private files automatically; resolve any interrupted-save journal
before downgrading. Private journal snapshots can contain API key copies; never
share them. No application is installed into /Applications by this build.
