# 1.0.2 — local repair candidate

Built 2026-11-17 for Apple Silicon macOS. This is a local candidate, not a
published release or a certification that every line/external service is correct.
Source baseline: `f1638f9d468e37226bfe8f17bbeca00313b47879` plus the uncommitted
approved repairs. Exact source/artifact fingerprints are recorded in
[1.0.2-evidence.json](1.0.2-evidence.json).

## Changes

- Explicit invalid-settings recovery preserves the original bytes and offers
  newest-valid backup or clean JSON. The current Mac's empty file was archived
  and recovered from its valid backup; API connectivity is a separate question.
- Provider cards contain their ordered enabled keys and model. Requests try
  A1 → A2 → B1, with bounded retries and cooldowns. Existing explicit-key routes
  keep their order unless converted explicitly.
- Fixed legacy-key Apply, indexed-key tests/discovery, provider pairing, enabled
  state, phantom migration, stale availability, failed-add data loss, stale async
  results and unintentional context resets. Explicit role/context resets added.
- Settings are validated before helper/key changes. Handled failures attempt
  secret/helper/index rollback. Metadata uses private unique temporary files;
  first-run settings creation refuses concurrent replacement. Multi-file crash
  atomicity and rollback success under disk failure are not guaranteed.
- Blocking Tauri commands use supported asynchronous dispatch. Proxy forwards
  protocol headers/caller-error responses and reports interrupted streams without
  replaying them. Attempts, elapsed upstream time and client concurrency are bounded.
- Four screens: Overview, Providers & keys, Switching and Recovery. Section/field
  info buttons, visible pending policy and save receipts, editable manual models,
  correct storage/backup text and explicit unsupported-provider explanations.
- OpenAI-only bridge install/start/apply are disabled, including command handlers.
- `npm run build:macos` builds the app and packages a plain drag-to-Applications
  DMG using Apple disk-image tools. This avoids the Finder AppleEvent timeout
  encountered in Tauri's image customization on this host.

## Using the candidate

Build with `npm run build:macos`. The DMG is in
`src-tauri/target/release/bundle/dmg/Claude Config Manager_1.0.2_aarch64.dmg`;
`SHA256SUMS` is alongside it. Final DMG SHA-256:
`79140a667145c904dd7d566818a725e7d7e7d5a328d906ac7554eba0d7231f49`. The app bundle is in `bundle/macos/`.
The packaging script verifies the image before replacing the final local file.

Choose a provider, add its keys, set its model, and add it to switching. Repeat
for the next provider; order the cards and **Save & enable automatic switching**.
See the [user guide](../USER_GUIDE.md). Automatic switching does not create extra
quota; keys may share account limits. Timeouts can leave upstream processing
uncertain. The helper is required while Claude Code points at loopback.

The local app is not notarized and macOS trust assessment rejects it. A normal
trusted distribution needs the owner's Apple Developer signing identity and
notarization. No system security settings are weakened by this repair.

Remaining improvements/acceptance work are in the
[54-item audit register](../audits/2026-11-17-project-review.md), including selected
backup previews, durable independent drafts, stronger transaction journaling,
rollback-failure reporting, broader stress tests and remaining manual review.

Research before implementation used the current official
[settings](https://code.claude.com/docs/en/settings),
[model configuration](https://code.claude.com/docs/en/model-config),

The dated audit contains provider-specific sources and the observed CLI version.
