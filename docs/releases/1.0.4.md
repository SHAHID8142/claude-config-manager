# 1.0.4 — built-in NVIDIA support

Local Apple Silicon candidate, 2026-11-17. Source remains uncommitted; no GitHub
push/release. Replaces the unavailable-provider limitation in 1.0.3.

## Use NVIDIA

Choose NVIDIA NIM → add its key(s) → enter/select a chat model → **Save & Apply**.
For the requested model, use `nvidia/nemotron-3-ultra-550b-a55b`. Save starts the
local helper, writes verified Claude Code settings and puts NVIDIA first in
switching order. Its enabled keys are tried before other retained providers.
Add-to-switching also works for configuring a policy before activation. Keep
the helper running; the GUI may close. No third-party bridge installation is
needed. Public catalog success does not verify a key or model inference.

## Implementation

The existing authenticated loopback helper translates Anthropic Messages to
NVIDIA Chat Completions and back: text, model-specific images, function schemas,
tool choice, assistant tool calls, tool results, JSON responses, streamed text,
parallel/fragmented tool arguments, stop reasons and usage. Caller errors return
an Anthropic-shaped error; auth/quota/temporary faults use existing key/provider
failover. Unsupported content is rejected before sending it; no replay after
stream start. Frame/response/tool buffers and concurrent work are bounded.

NVIDIA has bounded connect/send/header waits and 120-second read idleness;
responses can stream for up to 30 minutes. The 60-second retry-decision budget
is checked between attempts, so an in-progress phase can finish later. NVIDIA
output is capped at 32,768 tokens. Nemotron 3 uses `enable_thinking: false` and
`force_nonempty_content: true`. Anthropic document/server/computer tools and
structured output are unsupported; thinking signatures/cache metadata are not
NVIDIA state. Other OpenAI-only providers and the dormant third-party bridge
remain unavailable. Tool execution stays with Claude Code, never the helper.

## Verification

- Frontend: lint, formatting, TypeScript and **206 tests PASS**.
- Rust: fmt, clippy warnings denied and **356 tests PASS**; six environment/live
  tests ignored in the default run.
- Real CLI integration explicitly executed: Save generated settings/helper →
  fixture key A1 got 401 → A2 streamed a Read tool call → installed Claude Code
  executed Read on a disposable test file → A2 streamed the final answer. Exact
  tool-result content, request path/model, key order and CLI exit were asserted.
- Socket regressions cover NVIDIA keys exhausting then a compatible provider
  serving its own model; caller errors; unsupported documents before any call;
  interrupted stream without replay. Activation failures restore the prior policy.
- The same CLI test is run against the signed packaged helper; see evidence JSON
  for final result and signature/image/hash checks.
- **No real provider keys or paid inference were used.** Hosted account credit,
  availability and actual model behavior remain unverified. All tool execution
  used isolated fixture files/homes with cleared credential environment.
- Signing is ad-hoc. Developer ID/notarization and clean-Mac Gatekeeper trust
  remain outstanding; local signature integrity is a separate check.

## Requested uninstall/cache cleanup

Removed `/Applications/Claude Config Manager.app`, its user LaunchAgent, and
bundle-specific `Library/Caches` and `Library/WebKit` folders to Trash. Stopped
the identified old helper. The current CLI settings use an external endpoint,
so no settings rewrite was needed to stop it. API key files, credential metadata,
routing policy, helper scripts, Claude settings and backups were preserved.
No replacement was installed into `/Applications`; the new app/DMG stays in the
project build output. Extra HTTPStorage/application-support bundle cache paths
were checked and absent. Any cache created by native candidate inspection is
cleared again after the inspection.

## Reproduce locally

```sh
npm run check:frontend
npm run check:rust
npm run build:macos
CCM_HELPER_EXE="$PWD/src-tauri/target/release/bundle/macos/Claude Config Manager.app/Contents/MacOS/claude-config-manager" cargo test --manifest-path src-tauri/Cargo.toml --test nvidia_cli -- --ignored --nocapture
```
