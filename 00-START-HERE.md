# Claude Config Manager — Autonomous Handoff v0.2
Read ALL files in this folder before starting. This pack replaces v0.1 wherever instructions conflict.

## Goal
Build a minimal Tauri 2 / Rust / React / TypeScript Claude Code CLI global configuration manager, macOS first and Windows-ready architecture. No integrated terminal. Provider templates, credentials, endpoint, model discovery/manual selection, safe Save & Apply, and consent-based open-source compatibility bridge. See PRD and security contract.

## Operating agreement
ONE initial authorization for the entire backlog. The coding agent then works **autonomously, sequentially, one small task at a time**, testing, auditing, committing and pushing each completed task. No approval between ordinary tasks. Stop only for a material security/architecture decision, credentials/permissions, destructive action, unresolvable blocker, or exhausted retry budget. Never bypass an actual platform approval prompt.

## Start
Give the coding agent the whole folder and paste `07-MASTER-AUTONOMOUS-PROMPT.md` once. The agent must read `04-TASK-BACKLOG.md` in full, maintain `TASK_PROGRESS.md`, and follow `03-AGENT-RULES.md`.

## Finish
The coding agent must run a full final audit and provide the GitHub repository URL, branch, final commit, test/build logs, known limitations, and install/run instructions. ChatGPT will then independently inspect the actual repository; agent self-certification is not final approval.

## Status
Specification only. No code has been implemented or audited. Current Claude Code configuration conventions and open-source bridge candidates must be verified before coding their integrations.
