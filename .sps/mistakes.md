# Review guardrails

- Passing unit tests do not establish a working installed provider workflow.
- A signature verification pass is distinct from Gatekeeper acceptance.
- “Configured”, “key checked” and “model request succeeded” are different states.
- Never claim byte-exact preservation when JSON is reserialized.
- Never call a settings-only rollback a full credential/helper transaction.
- Keep the remaining manual review and native/live acceptance work visible.
