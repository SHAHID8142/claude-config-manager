# Project workflow

## /sps lock

This project uses the installed `sps` skill. Read `.sps/profile.md`,
`.sps/handoff.md`, `.sps/plan.md`, and the skill's `METHOD-CARD.md` before work.
Implementation requires plan approval; see `.sps/plan.md` for the concrete scope.
User instructions take precedence. Never expose API keys or test real paid
providers without the relevant authorization. Use fixture homes for tests.

Keep findings evidence-backed. The audit is a baseline, not proof that every
line is correct. Record unverified release, UI, and live-provider checks.
